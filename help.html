🐇 Centre d'aide

Bienvenue dans le centre d'aide officiel de Hare Browser. Ce navigateur web combine un environnement de navigation multi-panneaux avancé (mode mosaïque dynamique), un moteur de recherche SearXNG respectueux de la vie privée et un assistant d'intelligence artificielle locale propulsé par Ollama.

🍏 Configuration macOS : Pour les utilisateurs d'Apple Mac, remplacez systématiquement la touche Ctrl par la touche Cmd (Commande) pour l'ensemble des raccourcis ci-dessous.

🧱 Gestion des panneaux & fonctionnement du fractionnement

Le cœur de Hare Browser repose sur un arbre binaire de division (Split Nodes). Chaque panneau actif peut être subdivisé géométriquement à l'infini pour organiser votre espace de travail sans manipuler des dizaines d'onglets superposés traditionnels.

Schémas géométriques de fractionnement des tuiles :

1. Scission Verticale Initiale (Ctrl + T) : Divise l'espace actif en deux colonnes égales et ouvre une nouvelle tuile indépendante sur le flanc droit.

    ┌──────────────────────────────────────┐          ┌──────────────────┬──────────────────┐
    │                                      │          │                  │                  │
    │                                      │ Ctrl + T │                  │                  │
    │            PANNEAU INITIAL           │ ───────> │  PANNEAU INITIAL │  NOUVELLE TUILE  │
    │               (Actif)                │          │                  │     (À droite)   │
    │                                      │          │                  │                  │
    └──────────────────────────────────────┘          └──────────────────┴──────────────────┘

2. Scission Horizontale Subsidiaire (Ctrl + H) : Sélectionne un panneau spécifique et le fracture en deux rangées horizontales, créant une nouvelle tuile en contrebas.

    ┌──────────────────┬───────────────────┐          ┌──────────────────┬──────────────────┐
    │                  │      FOCUS        │          │                  │   TUILE DU HAUT  │
    │                  │     (Actif)       │ Ctrl + H │                  ├──────────────────┤

    │                  │                   │          │                  │     (En bas)     │

➕ Scinder un panneau avec le bouton +

Vous pouvez créer rapidement un nouveau panneau sans utiliser le clavier. Cliquez simplement sur le bouton + situé à droite de la barre d'adresse du panneau actif.

💡 Astuce : le bouton + effectue une scission verticale du panneau sélectionné et ouvre immédiatement une nouvelle tuile à droite.

🖱️ Menu contextuel des panneaux

Chaque panneau de navigation dispose d'un menu contextuel accessible par clic droit. Ce menu regroupe les principales actions de gestion du contenu, les fonctions d'intelligence artificielle et les outils d'agencement de la mosaïque.

💡 Astuce : un clic droit dans un panneau permet d'accéder rapidement aux commandes les plus courantes sans utiliser les raccourcis clavier.

✏️ Édition

  • Couper (Ctrl + X)
  • Copier (Ctrl + C)
  • Coller (Ctrl + V)
  • Supprimer
  • Sélectionner tout (Ctrl + A)

🤖 Actions IA (Assistant)

  • Résumer cette tuile web : génère un résumé rapide de la page affichée.
  • Analyser les mots-clés de la page : extrait les principaux thèmes et mots importants du contenu.

🧱 Agencement de la mosaïque

  • Scinder verticalement (Ctrl + T) : crée un nouveau panneau à droite.
  • Scinder horizontalement (Ctrl + H) : crée un nouveau panneau en dessous.
  • Scinder en Navigation Privée (Ctrl + Shift + N) : ouvre un nouveau panneau privé isolé.
  • Scinder dans un conteneur isolé (🗂️ dans la barre d'outils) : ouvre un nouveau panneau dans un conteneur (Personnel, Travail, Compte 2, Compte 3) pour se connecter à plusieurs comptes simultanément.
  • Dupliquer cette tuile (Ctrl + Shift + D, 📋 dans la barre d'outils, ou clic droit sur la tuile) : ouvre une copie du panneau à sa droite, sur la même adresse. La copie d'une tuile privée reste privée ; celle d'une tuile conteneur est créée dans la session par défaut.

📌 Gestion du panneau

  • Maximiser cette tuile (Ctrl + M) : agrandit temporairement le panneau sélectionné.
  • Imprimer le contenu de la page (Ctrl + P).
  • Fermer cette tuile (Ctrl + W).

Le menu contextuel constitue le point d'accès central à la plupart des fonctionnalités de gestion des panneaux. Il permet notamment de construire rapidement un espace de travail en mosaïque, d'analyser une page avec l'assistant IA et de gérer le contenu affiché sans quitter le panneau actif.

✨ Fonctions Avancées

🤖 Assistant IA Ollama Local

Hare Browser embarque un agent conversationnel autonome connecté à votre instance locale d'Ollama. Il est capable d'analyser le contenu textuel de votre page web active pour générer des résumés concis en trois points clés ou en extraire des mots-clés spécifiques, garantissant une confidentialité totale (aucune donnée n'est transmise à un serveur tiers ou Cloud externe).

🕵️ Cyber-Sécurité et Navigation Privée

Lorsque vous ouvrez une tuile privée, le navigateur instancie une partition en mémoire pure volatile (session incognito isolée). Lors de la fermeture de cette tuile, un script détruit automatiquement toutes les traces locales résiduelles de manière irréversible : cookies, LocalStorage, bases IndexedDB, session et cache d'historique de rendu HTTP de Chromium.

� Mode Lecture

Le bouton 👓 transforme la page affichée en une vue épurée : seuls le titre, le texte, les images et les tableaux de l'article sont conservés, sans menus, publicités, bandeaux ni commentaires. Il est disponible à trois endroits : dans la barre d'outils (il agit sur la tuile active), dans la barre d'adresse de chaque tuile, et dans le menu contextuel (clic droit, « Mode lecture »).

  • Confort de lecture : texte centré en police à empattements, adapté au mode clair ou sombre de l'application. Les boutons A− / A+ ajustent la taille du texte.
  • Quitter : cliquez sur ✕ dans la barre du mode lecture, ou sur � à nouveau. La page d'origine n'est pas rechargée : vous retrouvez exactement votre position.
  • Limites : indisponible sur les pages internes ou en veille. Si la page contient trop peu de texte, l'icône affiche brièvement ⚠️.

⬇️ Gestionnaire de Téléchargements

Le bouton ⬇️ de la barre d'outils (ou Ctrl + J) ouvre une fenêtre qui liste vos téléchargements en cours et passés, avec le nom du fichier, la taille et le site d'origine.

  • En cours : une barre de progression est affichée et le bouton « Annuler » interrompt le téléchargement.
  • Terminés : le bouton « Ouvrir le dossier » affiche le fichier dans l'Explorateur. Si le fichier a été déplacé ou supprimé, la ligne l'indique.
  • Liste : ✕ retire une ligne, « Effacer la liste » retire tous les téléchargements terminés (les fichiers ne sont jamais supprimés). L'historique est conservé entre les lancements, sauf pour les tuiles privées : leurs téléchargements ne sont jamais enregistrés sur disque.

️ Tuiles Conteneurs (Multi-Comptes)

Chaque conteneur dispose de sa propre partition persistante : cookies, LocalStorage et sessions y sont isolés des autres conteneurs et de la session par défaut. Vous pouvez ainsi ouvrir deux tuiles côte à côte et vous connecter à deux comptes Google ou Outlook différents en même temps. Contrairement à la navigation privée, les connexions sont conservées entre les lancements.

  • Ouverture : bouton 🗂️ de la barre d'outils, ou clic droit sur une tuile puis « Scinder dans un conteneur isolé (comptes multiples) », puis choix du conteneur.
  • Repérage : l'onglet d'une tuile conteneur est surmonté d'un liseré coloré ; le nom du conteneur s'affiche au survol.
  • Limites : indisponible depuis une tuile privée ou en mode agrandi. « Dupliquer cette tuile » crée la copie dans la session par défaut, pas dans le même conteneur.

🚫 Bloqueur de Publicités & Trackers Intégré

Chaque requête réseau émise par une tuile (qu'elle soit publique ou privée) est analysée à la volée par le processus principal de l'application via l'API webRequest d'Electron.

  • Vitesse accrue : Les scripts publicitaires lourds et les images intrusives sont annulés avant leur téléchargement.
  • Respect total de la vie privée : Bloque nativement les mouchards de suivi comportementaux des régies publicitaires majeures.
  • Protection Incognito : Le filtrage s'applique de manière hermétique sur vos partitions volatiles sans laisser de traces en mémoire.
  • Désactiver le bloqueur sur un site : si un site fonctionne mal, cliquez sur l'icône 🛡️ de sa barre d'adresse, ou faites un clic droit sur la tuile puis « Désactiver le bloqueur sur nom-du-site ». La page est rechargée sans filtrage. L'icône devient verte pour indiquer l'exception ; un nouveau clic réactive le bloqueur. Les exceptions sont enregistrées par site et conservées entre les lancements.

🔑 Gestionnaire de Mots de Passe Sécurisé

Vos identifiants et mots de passe enregistrés sont protégés par chiffrement fort. En mode développement ou sur les systèmes cibles compatibles, le navigateur s'appuie sur le module safeStorage pour appliquer un chiffrement asymétrique interne (Alternative Encryption), bloquant toute lecture non autorisée du fichier de stockage par des applications tierces.
